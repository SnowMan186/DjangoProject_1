Это учебный проект интернет-магазина, создаваемый в рамках курсового задания. Проект позволяет пользователям просматривать каталог товаров и отправлять контактные данные через страницу контактов.

**Описание структуры проекта**

- **settings.py**: Основные настройки Django.
- **urls.py**: Маршрутизация сайта.
- **catalog/**: Приложение каталога продуктов.

**Используемые технологии**

- Python/Django
- Bootstrap (для фронтенда)
